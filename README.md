# ferramenta de cadastro de clientes
Este é um projeto simples e prático desenvolvido em Python para gerenciar o cadastro de clientes de forma descomplicada. Ele conta com uma interface gráfica amigável e salva todas as informações com segurança.


O que este projeto faz?
Interface Gráfica: Uma janelinha simples criada com Tkinter onde você digita o nome, sobrenome, e-mail e telefone do cliente.

Banco de Dados Local: Utiliza SQLite3 para armazenar automaticamente todos os dados inseridos em um arquivo local (banco_clientes.db).

Exportação para Excel: Com apenas um clique, o sistema pega tudo o que foi cadastrado no banco de dados e gera uma planilha organizada em formato Excel (clientes.xlsx) usando a biblioteca Pandas.

Tecnologias utilizadas
Python

Tkinter (para a interface visual)

SQLite3 (para o banco de dados)

Pandas (para a manipulação e exportação dos dados para o Excel)
